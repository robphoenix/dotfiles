## LinkedIn About section

Senior Software Engineer specialising in AI-ready Design Systems, building
the foundations, tooling, and guardrails that agentic AI workflows need
across product teams.

My job is keeping systems coherent as products scale and drift. That goes
beyond typical UI work: I build automated Figma-to-code token pipelines,
generate cross-platform icon libraries, and engineer scalable, accessible
CSS and React components, backed by Storybook environments, visual
regression testing, and clear usage guidelines. I work closely with UX on
design review, feedback loops, and long-term system governance, and I write
custom developer tooling to automate the repetitive work that slows teams
down.

For me, structured documentation and strategic "human gates" are core parts
of this Design Systems infrastructure. Documentation is a first-class
product feature, whether it's read by engineers or an LLM. Pairing clear
guidelines with programmatic guardrails lets teams generate and validate UI
quickly, without sacrificing quality, accessibility, or architectural
integrity.

Production ownership and accessibility run through all of it. I build
accessibility in deliberately, from early UX design through automated
testing to clear guidance for developers. I also own the full production
lifecycle: technical strategy, release management, and Linear workflows,
driving adoption, gathering feedback, and giving hands-on support.

Beyond the systems themselves, I care about developer culture. I like
mentoring engineers, running knowledge-sharing sessions, and working across
UX and product to build the workflows and governance that let engineering
orgs scale without falling apart.
